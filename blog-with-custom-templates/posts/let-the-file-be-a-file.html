Let the file be a file

Avoid a runtime when it cannot change the answer.

If every visitor receives the same document, the document already knows what it needs to be. Store it, cache it, and serve it directly.

A runtime is valuable when a request changes the result: identity, fresh data, a mutation, or private context. Without one of those reasons, it adds another moving part to an answer that was complete on disk.

Static is not a lesser mode. It is the honest shape of a fixed answer.

Start with the file. Add execution only at the edge where the answer genuinely becomes dynamic.
