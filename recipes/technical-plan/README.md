# Technical planning

Northstar Sync is a decision-ready technical plan for adding offline-first project
sync to a collaborative field-operations product. The static site turns a realistic
engineering RFC into a readable planning artifact: executive recommendation, scope
boundaries, architecture and data flow, phased milestones, ranked risks, recorded
decisions, and owned open questions.

The demo is plain HTML and CSS with no build step. Open `site/index.html` directly,
or serve `site/` with any static file server. It is responsive, keyboard-friendly,
and designed to print cleanly for an architecture review. See `prompt.md` to build
your own version from the recipe.

The intended catalog URL is <https://technical-plan.view.fast/>. This worktree does
not publish it.
