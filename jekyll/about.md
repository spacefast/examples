  <p class="eyebrow">About the notebook</p>
  <h1>Slow notes for fast-moving work.</h1>
  <p>Small Hours is a compact Jekyll example: Markdown in, semantic HTML out, and no application server between a reader and the page.</p>
  <p>The project stays intentionally ordinary. That is the point. Spacefast detects the framework, runs the build, finds <code>_site</code>, and publishes the result without a platform-specific plugin.</p>
